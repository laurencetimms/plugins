# Laurence Timms – Claude plugins

A plugin marketplace for Claude.

| Plugin | What it does |
| --- | --- |
| [Beyond the Headlines](plugins/beyond-the-headlines) | News analysts that see past the headlines. Starts with the AI News Analyst: a weekly brief on what AI is doing to work, power, knowledge and people, following your own interests. |

## Install

**Claude (web and desktop):** go to Customize > Plugins, choose Add marketplace, and enter `laurencetimms/plugins`. Then find Beyond the Headlines under Discover and click Add.

**Claude Code:**

```bash
claude plugin marketplace add laurencetimms/plugins
claude plugin install beyond-the-headlines@laurencetimms
```

Then start a chat and say **"Set up my AI news analyst"**.

**Without a plugin:** the skill is also available as a ZIP to upload in Customize > Skills, on any Claude plan. See [laurencetimms.com](https://laurencetimms.com).
