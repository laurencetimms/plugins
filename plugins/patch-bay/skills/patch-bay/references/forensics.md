# Synth Forensics

## Song → machines

1. Check the graph: `python3 scripts/graph.py find <title>` then `show <id>`.
2. Research regardless, under `references/sourcing.md`. The seed rarely has every part. Look first for interviews with the people in the room.
3. Answer part by part where the sources allow:

   **Blue Monday (New Order, 1983)**
   - Drums: Oberheim DMX (reported)
   - Bassline: Moog Source (reported)
   - Choir: an E-mu Emulator sampling Kraftwerk's "Uranium" (reported)

   Then a short paragraph on how it was put together if the sources say: the trick, the accident, the borrowed machine, the sync problem. This is the bit people remember.
4. Say plainly what isn't known.
5. Note when a song exists in several versions (single, album, 12", re-recording) and which one the sources describe. "Being Boiled" has at least three.

## Machine → songs

"What else used a Jupiter-8?", or as the follow-on to any song answer.

1. `python3 scripts/graph.py machine <id>` for the seed's links.
2. Research a handful more. Order them so the surprising ones come first: the unexpected genre, the obscure B-side, the record nobody thinks of as electronic. The famous examples can come last, briefly.
3. Grade each one. Album-level credits say so.
4. Offer the list as a playlist in one line.

## Sound → machine

"What makes that 80s gated snare?", "what's the Vox Humana sound?". Explain the technique or preset, name the records where it is documented, and separate the machine from the technique: a sound can often be made several ways, and the famous version used one of them.

## Tone

Specific and story-led. A nerd's delight in the detail, kept short. If the user clearly knows the kit, talk to them as a peer.
